Python for AI

A hands-on Python course built for artificial intelligence, machine learning and data science. It goes from Python basics to NumPy, Pandas, Matplotlib and regular expressions, and ends with a final project.

Instructor: Zahra Amini

Term: Online

Location: Online, Hobot Academy

Time: Self-paced video lectures

Course Overview

This course was designed and taught by me at Hobot Academy. It gives students a strong Python foundation for artificial intelligence, machine learning and data science. Students will:

  • Learn Python from the basics: variables, control flow, lists, loops, functions, tuples, dictionaries, sets and files
  • Use NumPy and Pandas for numerical computing and data manipulation
  • Visualize data with Matplotlib
  • Process text with regular expressions
  • Apply everything in a final project

Resources

  • Course repository on GitHub with source code, Jupyter notebooks and exercises
  • Course page on Hobot Academy (Persian)

How to Use the Materials

  1. Clone the repository: git clone https://github.com/hobotacademy/Python-for-AI.git
  2. Install Python, Jupyter Notebook, and the libraries used in the course (NumPy, Pandas, Matplotlib)
  3. Open the cloned folder, run jupyter notebook, and work through the notebooks in order
